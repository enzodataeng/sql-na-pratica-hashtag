# SQL na Prática — Projetos Hashtag Treinamentos
 
Repositório com os projetos desenvolvidos ao longo do curso de **SQL** da [Hashtag Treinamentos](https://www.hashtagtreinamentos.com/), integrando SQL a diferentes ferramentas de análise e visualização de dados: **Excel**, **Power BI** e **Python**.

| Projeto | Stack | Descrição | Status |
|---|---|---|---|
| [`projeto-01-adventure-works-excel`](./projeto-01-adventure-works-excel) | SQL Server + Excel | Dashboard de resultados de vendas (receita, custo, sazonalidade, categorias e gênero) a partir da base Adventure Works | ✅ Concluído |
 
## 🎯 Sobre este repositório
 
O objetivo é consolidar em um único lugar a prática de SQL aplicada a diferentes contextos de análise de dados:
 
- **SQL + Excel** — consultas para alimentar tabelas e dashboards, com foco em modelagem simples e visualização executiva
O projeto parte da estrutura ensinada no curso, mas eu documento as decisões próprias de análise, modelagem ou visualização que fui além do conteúdo original — essas melhorias ficam detalhadas no README de cada pasta.
 
## 🛠️ Tecnologias utilizadas no repositório
 
- SQL Server
- Excel
