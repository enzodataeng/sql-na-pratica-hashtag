## 🎯 Sobre este repositório
 
O objetivo é consolidar em um único lugar a prática de SQL aplicada a diferentes contextos de análise de dados:
 
- **SQL + Excel** — consultas para alimentar tabelas e dashboards, com foco em modelagem simples e visualização executiva
- **SQL + Power BI** — consultas otimizadas para modelos de dados e relatórios interativos
- **SQL + Python** — automação de extração/tratamento de dados e análises mais robustas com bibliotecas como pandas
Os projetos partem da estrutura ensinada no curso, mas em cada um eu documento as decisões próprias de análise, modelagem ou visualização que fui além do conteúdo original — essas melhorias ficam detalhadas no README de cada pasta.
